# Посмотри в окно

Проектная работа Яндекс Практикума: оформление приложения для поиска и просмотра видео из разных городов.

Репозиторий: https://github.com/petrtochilkin/posmotri-v-okno-ad

Использованы Flexbox, локальные шрифты, кастомные чекбоксы и состояния интерактивных элементов. Исходная логика поиска, загрузки и переключения видео сохранена.

Для запуска откройте `index.html` в браузере или используйте локальный HTTP-сервер. Для загрузки видео нужен доступ к API проекта.
